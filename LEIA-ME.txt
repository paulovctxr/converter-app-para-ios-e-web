Como atualizar o site
1. Extraia este ZIP.
2. Copie todas as pastas sobre a pasta do projeto no seu computador.
3. No GitHub Desktop, confira os arquivos alterados.
4. Escreva o resumo: Acesso automático para novos cadastros
5. Clique em Commit to main.
6. Clique em Push origin.
7. Aguarde o Vercel mostrar Ready.
