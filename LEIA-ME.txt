IMPORTANTE SOBRE O SUPABASE

O envio automático para o Supabase não foi concluído nesta sessão porque a aprovação da ferramenta atingiu o limite de uso. Portanto, faça os dois passos abaixo uma vez:

1. Supabase > SQL Editor.
2. Abra o arquivo:
   supabase/migrations/20260929221500_nutrition_ai_food_tools.sql
3. Copie todo o conteúdo, cole no SQL Editor e clique em Run.
4. Supabase > Edge Functions > Create a new function.
5. Crie a função com o nome:
   nutrition-ai-tools
6. Copie o conteúdo de:
   supabase/functions/nutrition-ai-tools/index.ts
   para o editor da função.
7. Se o editor aceitar arquivos auxiliares, adicione também o deno.json da mesma pasta.
8. Publique a função.

A função precisa manter verify_jwt ativado e usar o segredo OPENAI_API_KEY já configurado.
Não coloque a chave em arquivos do projeto ou em variáveis NEXT_PUBLIC_*. 

COMO PUBLICAR O FRONTEND

1. Extraia este ZIP.
2. Copie as pastas "app", "components" e "lib" para a raiz do projeto.
3. Copie também a pasta "supabase" para a raiz, caso ainda não tenha os arquivos novos.
4. Confirme a substituição dos arquivos.
5. No GitHub Desktop, faça Commit to main.
6. Clique em Push origin.
7. Aguarde a Vercel mostrar Ready.

Como testar:
- Entre com uma conta PRO.
- Abra Nutrição > Foto da comida.
- Escolha uma foto, clique em Analisar com IA, revise e confirme.
- Abra Cardápio e clique em Substituir com IA em uma refeição.
